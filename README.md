# MM2 Farm

Скрипт автофарма MM2 (Roblox) для исполнителя Lynx.

## Установка

1. Скопируй `MM2FarmLoader.lua` в Lynx → AutoExec и включи его.
2. Зайди в MM2 — загрузчик скачает свежий `MM2Farm.lua` с этого репозитория и запустит его.
3. HUD появляется слева сверху: Пауза / Режим / Пасс / Забрать / Хоп / HUD / Стоп.

Загрузчик добавляет `?v=<время>` к ссылке, чтобы CDN не отдавал старую версию из кэша.

## Режимы

- `FLY` — полёт через CFrame по кадрам, без телепортов; стены не мешают.
- `WALK` — обычный наземный сбор.

Авто-реджойн по умолчанию выключен, анти-АФК работает по схеме ZaLupa Hub.
